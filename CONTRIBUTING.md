# Contributing to Codex Blue Book

Thank you for helping improve **Codex Blue Book**!

- **Found a typo, outdated CLI flag, or model pricing change?** Open an Issue directly in this repository, or submit a Pull Request to the single-source hub repository: **https://github.com/aipmer/ai-coding-blue-books**.
- **How publishing works:** All chapters, bilingual PDFs, and companion kits are authored, tested, and built in `aipmer/ai-coding-blue-books`, then synced automatically to this standalone repository.
- **Online reading:** https://book.pmer.cn/codex/ (中文) · https://book.pmer.cn/en/codex/ (English)
