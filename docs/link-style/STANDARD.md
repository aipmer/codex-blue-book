# 文字链接与跳转图标规范 1.0.0

本规范随 Web UI Quality 1.1.0 发布。适用于正文、来源、说明、定价与比较中的文字链接；导航、整卡链接、标签、实心按钮保持各项目组件语义。项目采用时提交本文件的受控副本与 SHA-256，不依赖本机绝对路径。

## 配色与交互

- 文字链接显式使用项目的可读主题色 token，不依赖浏览器默认蓝色/紫色，也不把 PMER 的绿色复制给其他品牌。`:visited` 不得回落到 UA 默认色。
- 正文文字链接默认有下划线，建议 `1px`、`text-underline-offset: .2em`；hover 可加粗下划线，键盘 `focus-visible` 必须清晰。不能只靠颜色辨认链接。
- 各主题使用对应的可读前景色；普通文字对实际背景的对比度至少 4.5:1。品牌装饰色不一定能直接作为小字颜色。检查真实背景，不只看 token 名称。
- 保留自然断行与完整文字；长 URL 可 `overflow-wrap: anywhere`。不使用固定换行、截断、全链接 `nowrap` 或把长段落改成 `inline-flex` 来强行容纳图标。

## 图标语义

- 站内继续阅读/下一步使用右箭头 `→` 或 `ArrowRight`；外部网页统一为小型「方框外跳」轮廓图标。外链不使用裸 `↗` 字符。
- HTTP(S) 或协议相对 URL 应按公开站点 origin 判定；同源绝对 URL仍是站内链接。路由组件保留语言、query 与应用状态。
- 下载用下载图标；`mailto:`、`tel:`、页内锚点用各自语义，不加外跳标记。`target="_blank"` 不是判定外链的唯一依据。
- 一个链接最多一个方向图标。渲染器、组件、CSS `::after` 三者只由一层插入；已有 SVG 时不得再加伪元素。VitePress 等框架自带图标时，覆盖现有图标，不再叠加。
- 外跳图标继承 `currentColor`，正文通常 14–16 CSS px、约 `.875em`，不得压缩；与文字间距约 `.3em`，基线对齐。多语排版共用一份图标，译文不携带方向符号。
- SVG/图标节点作装饰时设 `aria-hidden="true"`。链接文字说明目的；图标本身不重复读出。不因样式任务改变链接目的地、打开方式或已有归因参数。
- CSS mask 图标使用空 `content`，并给强制颜色模式提供可辨识外形；不向屏幕阅读器插入含义重复的文本箭头。

## 实现与验收

先枚举共享组件、样式、生成器和全部消费者，检查 CSS 级联与计算结果；修事实源后按项目生成流程更新必要产物。只在正文/文字链接范围内应用样式，不给全站 `a` 强加颜色、下划线或外链伪元素。

普通链接样式改动按影响选择代表页面、项目适用的语言/主题，以及窄屏、平板、桌面三个宽度；没有改排版、字号或容器时，不额外跑全站排版审计。需要检查链接 computed color、下划线、图标数量/颜色/实际大小、长文案断行与键盘 focus。项目原有的必要门禁仍执行。当前候选有变更再更新相关结果。

本地、构建产物、Production Ready、正式域名生效分别记证据。缺少构建依赖或浏览器结果时记录未验证，不能记通过。发布仍须有明确授权；本规范不授予提交、推送或生产部署权限。
